      Data from the GitHub traffic API, collected daily by a GitHub Action. GitHub keeps only 14 days, so history here starts on each repo's “tracked since” date (back-filled 14 days on first run). “Unique” counts are per repo per day: one person visiting two repos, or on two days, counts more than once. Clone counts include GitHub Pages builds, CI and crawlers; views are the better signal of human interest.
